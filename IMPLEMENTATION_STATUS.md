## Phase R — 3D Items & Item Texture Art

### 🟢 COMPLETED — R1: Voxel 3D held items, third-person items, dropped items

- **Files:** `rendering/model/ItemModel3D.java` (new), `HeldItemRenderer.java`, `PlayerBodyRenderer.java`, `Renderer.java`, `TextureAtlas.java` (`getLayerPixels`), `Game.java`
- **Implementation:**
  - `ItemModel3D` turns a 16×16 sprite into a chunky 3D model: every non-transparent pixel becomes a box in a thin layer (`DEPTH=0.16`), CCW winding with backface culling, cached per atlas layer, rendered through the existing `heldblock` shader (`faceLayers[6]` uniform, alpha cutout)
  - First person (F1): flat `ItemSprite` quads removed; held items render as the voxel model in the `HandTuning` pose (still adjustable via F6)
  - Third person (F5): `PlayerBodyRenderer.render(..., ItemStack heldStack, ...)` draws the held voxel model in the hand
  - Dropped items: `Renderer.renderSpriteItemEntities(...)` draws each entity as the voxel model (scale 0.45, spin)
- **Testing:** build + `--headless` → 132/132 PASS

### 🟢 COMPLETED — R2: Real item sprites + PNG-first pipeline

- **Files:** `tools/gen_item_textures.py` (new), `TextureAtlas.java` (≈55 registrations switched `tileGenerated` → `tileSprite`), 58 new PNGs under `textures/blocks/`
- **Implementation:**
  - New procedural art: tools already existed (`gen_tool_textures.py`); added recognizable silhouettes for bread, apple, meats, drumsticks, bow (curved limb + string), arrow, potion bottles, armor (helmet/chestplate/leggings/boots × leather/iron/diamond/meteorite), gems, ingots, coal, bone, leather, feather, egg, wheat, shears, bucket, milk, slime ball, resin/wax, etc.
  - Item registrations now prefer bundled PNG and fall back to the procedural generator (`tileSprite` semantics), keeping the atlas valid even without the PNGs
- **Testing:** build + `--headless` → 132/132 PASS

### 📋 PENDING — R3: Item animations (bow draw, eating, block-break tooth)

## Tasks Implemented in This Session

### 🟢 COMPLETED — CRITICAL (🔴)

#### GP-020: Interactive Blocks (Doors)
- **Files:** `world/block/Interactable.java`, `world/block/DoorBlock.java`, `BlockType.java`, `physics/Raycast.java`, `Game.java`
- **Implementation:**
  - New `Interactable` interface (`boolean onInteract(World, int x, int y, int z)`) and `DoorBlock` singleton
  - New block types: `OAK_DOOR` (solid) and `OAK_DOOR_OPEN` (non-solid cross-quad)

  - Door textures generated by `TileGenerator.door(boolean)`; open door rendered as two framed panels with transparent gap
- **Testing:** Right-click a door → opens/closes; walk through the opening; break → drops closed door

#### GP-002: Half-Block Collision (Slabs)
- **Files:** `BlockType.java`, `World.java`, `Player.java`, `world/entity/Zoloy.java`, `rendering/GreedyMesher.java`, `rendering/TextureAtlas.java`, `item/BlockHarvest.java`
- **Implementation:**
  - New block types: `OAK_SLAB`, `STONE_SLAB` (bottom-half slab, y..y+0.5)
  - `World.getBlockAabb()` returns per-block AABB; player/mob collision, stepping and gravity all AABB-aware
  - Greedy mesher emits slab faces separately (`emitSlabs`) with AABB-based face culling (`covers()`); slabs never occlude full blocks
- **Testing:** Place a slab → walk onto it (0.5 step-up); place full block beside slab → correct side faces; break with pickaxe (stone slab needs wood+ pickaxe)

#### GR-002: Chunk Fade-In
- **Files:** `Renderer.java`, `shaders/block.frag`
- **Implementation:** `fadeAlpha` uniform in block shader; `RenderChunk` fades alpha 0→1 over 400 ms on first build; blended render pass while fading
- **Testing:** Load a new world / fly fast → newly built chunks fade in smoothly instead of popping

#### UI-016: Craft Result Preview (Survival Inventory)

## Architecture Notes

### File Structure
```
src/main/java/com/voxelgame/
├── core/          # Game, Settings, KeyBindings, Language
├── player/        # Player (physics, health, inventory)
├── world/         # World, Chunk, BlockType, LightEngine
│   ├── entity/    # Zoloy, ItemEntity, TntEntity, Villager
│   ├── biome/     # Biome system
│   ├── generator/ # Terrain generation
│   ├── save/      # World save/load
│   └── water/     # Water simulation
├── rendering/     # Renderer, Shader, Camera, Skybox
│   ├── model/     # HeldItemRenderer, BlockCube
│   └── texture/   # TextureAtlas, TextureRegistry
├── ui/            # GameHud, UIRenderer, FontRenderer
│   ├── screen/    # All screen classes
│   ├── toast/     # Toast system
│   └── widget/    # UI widgets
├── item/          # Inventory, ItemStack, Item, RecipeRegistry
├── audio/         # AudioManager, SoundLoader
├── chat/          # ChatManager, commands
├── physics/       # AABB, Raycast
└── achievement/   # Achievement system
```

### Key Patterns Used
- **Observer/Callback:** DeathCallback, screen callbacks
- **State Machine:** Mob AI (PATROL/CHASE/ATTACK)
- **Strategy:** Different tool tiers, block types
- **Factory:** ItemRegistry, RecipeRegistry
- **Worker Pool:** ChunkLoader with ExecutorService
- **ECS-lite:** Entities (Zoloy, ItemEntity) with update loops
