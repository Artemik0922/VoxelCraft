# 🧑🌾 Villager Textures Generator / Генератор текстур жителей

Python-скрипты для процедурной генерации **HD-текстур жителей в новом
стиле** (1024x1024 px на профессию — в 16 раз детальнее ванильных 64x64).
Атлас из 16 профессий: **16384x1024** — максимум `GL_MAX_TEXTURE_SIZE`
(Radeon RX 580).

## 📁 Файлы

| Файл | Описание |
|------|----------|
| `generate_villager_hd.py` | Основной генератор — 16 профессий, биомы, baby/zombie в 1024x1024 |
| `render_preview.py` | Рендер-превью «как в игре» (фронтальный вид жителя из скина) |
| `verify_hd.py` | Проверка: регионы заполнены, размеры, атлас |
| `generate_villager_atlas.py` | *Старый* генератор 64x64 (не запускать — перезапишет HD) |
| `generate_villager_variants.py` | *Старый* генератор baby/zombie 64x64 |
| `run_all.py` | Запускает HD-генератор |
| `README.md` | Этот файл |

## 🚀 Использование

```bash
pip install Pillow

# Сгенерировать все текстуры (1024x1024, атлас 16384x1024)
python run_all.py            # или python generate_villager_hd.py

# Превью-рендеры (preview_all.png, preview_variants.png)
python render_preview.py

# Проверка текстур
python verify_hd.py
```

## 👨🌾 Профессии (новый стиль)

- **Farmer** — коричневая роба, кожаный фартук, соломенная шляпа
- **Librarian** — фиолетовая роба с жилетом, очки, седые волосы
- **Blacksmith** — серая роба, прокопчённый фартук, сажа
- **Butcher** — белая роба, белый колпак, красный фартук с пятнами
- **Priest** — пурпурная роба с золотом, митра
- **Fisherman** — синий плащ с капюшоном, жёлтая отделка
- **Fletcher** — зелёный капюшон, ремень колчана
- **Leatherworker** — кожаный фартук со строчкой
- **Shepherd** — кремовая роба, шерстяной ворот, соломенная шляпа
- **Toolsmith** — фартук со строчкой, рыжие волосы
- **Armorer** — клёпаный фартук, металлические пластины
- **Weaponsmith** — красная бандана, тёмный фартук
- **Cartographer** — свиток на поясе, очки, золотая отделка
- **Cleric** — белая роба с золотой отделкой
- **Mason** — серый колпак, фартук в каменной крошке
- **Nitwit** — зелёная роба, взъерошенные волосы

## 🎨 Особенности нового стиля

- **Согласованный вид жителя**: тон кожи, цвет глаз и волос выбираются
  один раз на скин (в старом генераторе для каждой части тела выбирались
  заново — лицо не совпадало с шеей)
- **Лица**: склера, радужка, зрачок, блик, веки, ресницы, брови, румянец,
  губы, блик на подбородке
- **3D-нос**: отдельный кубик с освещением (верх светлый, бока темнее,
  низ в тени, ноздри)
- **Ткань**: плетение нитей, вертикальный градиент света, шум, затенение
  краёв
- **Швы UV-регионов**: лёгкое AO по границам кубов (эффект ванильных швов)
- **UV-раскладка** совместима с `VillagerModel` (Minecraft 64x64, ×16)

## 🔧 Рендер в игре

`VillagerRenderer` использует дробные координаты тайла (`1/16`), поэтому
атлас 16384x1024 работает без изменения математики; константы описаны
для новой раскладки. Требование: `GL_MAX_TEXTURE_SIZE >= 16384`
(в логе игры выводится при старте).
